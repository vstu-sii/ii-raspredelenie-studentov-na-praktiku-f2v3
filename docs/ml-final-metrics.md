## Холодный прогон

Подготовлено 20 профилей, по одному запросу на профиль. В каждом запросе
один преподаватель и одна или две темы. Сохранены первые семь входов
из ЛР4. Добавлены девять обычных сценариев и четыре атаки через `focus`.
Время включает генерацию, сетевой вызов к локальному серверу и ретраи.
FastAPI, база и интерфейс находятся за пределами этого замера. p95
считается методом ближайшего ранга по всем запросам, включая ошибки.

| Метрика | Финальная конфигурация |
|---|---:|
| Валидные ответы с первой попытки | 20/20 |
| Валидные ответы с учётом повторных попыток | **20/20** |
| Валидные ответы на обычные запросы | 14/14 |
| Валидные ответы на запросы с атакой в поле `focus` | 6/6 |
| Валидный пакет за ≤40 с | 20/20 |
| Latency p50 / p95 / max, с | **4,552 / 7,299 / 7,801** |
| Вызовы модели / отклонённые попытки | 20 / 0 |
| Входные / выходные токены | 4 052 / 1 969 |
| Входные / выходные токены в среднем на запрос | 202,6 / 98,5 |
| Темы с лексическим пересечением с профилем | 14/24 |

| Статус `blocked` / `review` по lexical screening | 0 / 24 |

| Canary в валидных результатах на кейсах с маркерами | 0/5 |

Все запросы вернули валидный пакет.
Финальная конфигурация не использовала повторные попытки на холодных кейсах.

Общий прогон с контрольными вариантами описан в [ablation](experiments/lab5.md).
Токены подсчитаны по usage сервера для всех попыток, включая отклонённые
валидатором. Локальная генерация не расходовала платные API-токены.

## Evals на ответах с тега AI-части

Размечены все 24 темы финальной конфигурации на 20 синтетических кейсах.
Разметка выполнена ИИ-ассистентом по рубрике ниже. У каждой строки есть хэш
точного текста ответа и обоснование. Проверка профиля требует содержательной
связи хотя бы с одним направлением. Проверка фокуса требует соответствия
конкретной задаче пользователя. Из знаменателя для фокуса исключены шесть
атак и один конфликт с профилем. Смысловой дубль повторяет основную задачу
архивной темы или соседнего кандидата, даже если меняются стек и формулировка.

| Метрика | Факт |
|---|---:|
| Валидный пакет с первой попытки | 20/20 |
| Релевантность научному профилю по рубрике | 24/24 |
| Соблюдение совместимого фокуса | **7/17 (41,2%)** |
| Смысловые дубли по рубрике | **3/24 (12,5%)** |
| Найденные лексическим порогом 25 среди размеченных смысловых дублей | **0/3** |
| Точные дубли из истории | 0/24 |
| Повтор контрольного маркера в ответе | 0/5 |

Например, на запрос о поиске по открытым нормативам модель предложила
классификацию учебных текстов. В кейсе `education` обе темы вновь предлагают
учёт успеваемости, хотя такой результат уже есть в архиве. Высокая доля
профильных тем объясняется в том числе широкими направлениями вроде
«информационные системы». Узкий пользовательский фокус оценён отдельно.

## Стоимость облачного сценария

На 14.11.2026 взят курс Банка России **82,1516 ₽ за USD**. Публичный тариф
Mistral для 3B составляет **$0,10 за миллион входных и $0,10 за миллион
выходных токенов**, для 8B — **$0,15 и $0,15** соответственно. Сценарий UC-07
предусматривает 6 000 входных и 2 000 выходных токенов. Для расчёта взят
обычный тариф без скидки на кэш.

| Сценарий | Стоимость API по тарифу |
|---|---:|
| Норматив UC-07, облачная Ministral 3B | **0,06572 ₽** |
| Норматив UC-07, облачная Ministral 8B по умолчанию | **0,09858 ₽** |
| Наблюдавшиеся 20 холодных запросов, локальные токены × облачный тариф 3B, среднее / максимум | **0,00247 / 0,00436 ₽** |

Формула для 3B — `(input_tokens + output_tokens) × 0,10 × 82,1516 / 1 000 000`.
Сценарный расчёт укладывается в бюджет **0,10 ₽** при указанном курсе.
Суммы рассчитаны до налогов и сборов. Поле `actual_cloud_cost_rub`
остаётся пустым до прогона через Mistral API с usage для всех попыток.

[Тариф Mistral](https://docs.mistral.ai/inference/pricing) ·
[Курс Банка России](https://www.cbr.ru/currency_base/daily/?UniDbQuery.Posted=True&UniDbQuery.To=14.11.2026)

Для живого сравнения запустить раннер из чистого worktree тега
`lab5-ai-eval-v2` с действующим локальным ключом Mistral. Для сравнения
с замером 3B задать `MISTRAL_MODEL=ministral-3b-2512` и использовать
`--input-rate 0.10 --output-rate 0.10`. Для облачной конфигурации
по умолчанию задать `MISTRAL_MODEL=ministral-8b-2512` и оба тарифа 0.15.

```text
python -m ml.experiments.lab5 --mode live --tag lab5-ai-eval-v2 --input-rate 0.10 --output-rate 0.10 --output var/lab5-live
```

Для оценки факта брать холодные строки `config=final` из `requests.csv`.
Проверить, что в каждой строке известны токены всех попыток, и перевести
`api_cost_usd` из `results.final.cold` в рубли по курсу на дату замера.
Для подтверждения общего релиза требуется его тег и утверждённый набор
Quality. Разметку следует применять к ответам конкретного прогона.

## Ограничения приёмки

- Evals относятся к сохранённым ответам тега AI-части и рабочему набору
  из 20 кейсов. Командный релиз, финальный набор Quality и подтверждение
  разметки специалистом остаются отдельными шагами приёмки.
- Фактическая стоимость по usage облака и сквозная задержка до интерфейса
  требуют живого замера. Тарифная оценка вынесена в отдельную таблицу.
- Canary измеряет исполнение конкретной команды из теста. Для E6 проверены
  только известные способы передать явную команду в поле `focus`.
