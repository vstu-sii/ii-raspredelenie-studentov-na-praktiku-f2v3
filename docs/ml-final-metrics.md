## Холодный прогон

Подготовлено 20 профилей, по одному запросу на профиль. В каждом запросе
один преподаватель и одна или две темы. Сохранены первые семь входов
из ЛР4. Добавлены девять обычных сценариев и четыре атаки через `focus`.
Время включает генерацию, сетевой вызов к локальному серверу и ретраи.
FastAPI, база и интерфейс находятся за пределами этого замера. p95
считается методом ближайшего ранга по всем запросам, включая ошибки.

| Метрика | Финальная конфигурация |
|---|---:|
| Валидные ответы с первой попытки | 20/20 |
| Валидные ответы с учётом повторных попыток | **20/20** |
| Валидные ответы на обычные запросы | 14/14 |
| Валидные ответы на запросы с атакой в поле `focus` | 6/6 |
| Валидный пакет за ≤40 с | 20/20 |
| Latency p50 / p95 / max, с | **4,552 / 7,299 / 7,801** |
| Вызовы модели / отклонённые попытки | 20 / 0 |
| Входные / выходные токены | 4 052 / 1 969 |
| Входные / выходные токены в среднем на запрос | 202,6 / 98,5 |
| Темы с лексическим пересечением с профилем | 14/24 |

| Canary в валидных результатах на кейсах с маркерами | 0/5 |

Все запросы вернули валидный пакет.
Финальная конфигурация не использовала повторные попытки на холодных кейсах.

Общий прогон с контрольными вариантами описан в [ablation](experiments/lab5.md).
Токены подсчитаны по usage сервера для всех попыток, включая отклонённые
валидатором. Для оплачиваемого облачного сценария тариф и фактическое
списание не измерялись. Локальный раннер не обращался к платному API,
его счёт за API составил 0 ₽. Стоимость оборудования и электричества
не входила в замер.

## Ограничения приёмки

- Показатели относятся к локальной AI-части. Экспертная приёмка тем,
  облачная цена сценария, сквозная задержка и evals на командном релизе
  требуют отдельных замеров. На момент прогона в репозитории отсутствовали
  командный релизный тег и финальный набор Quality.
- Профильное пересечение слов и пороги lexical 25/50 относятся к
  предварительному скринингу. Для E3 нужна проверка смысловых дублей,
  для E4 — оценка профильности специалистом.
- Canary измеряет исполнение конкретной команды из теста. Для E6 проверены
  только известные способы передать явную команду в поле `focus`.
