# ADR лабораторной 4. Генерация тем ВКР

## 1. Управляемое включение промпта v2

Решение. Оставляем v1 по умолчанию, v2 и v2-compact доступны через конфигурацию.
Кандидатов сравниваем на одинаковых входах и той же модели. Слепая разметка
использует отдельный ключ соответствия. Условие переключения — подтверждённый
прирост по критериям в `docs/experiments/lab4.md`.

Цена решения. Поддерживаем три варианта и разметку. V2 увеличивает размер
инструкций, а v2-compact может упустить прошлую тему за пределами примеров.
Полная история по-прежнему участвует в существующем лексическом скрининге.
Смысловые дубли пока оценивает человек.

## 2. Локальный кэш с TTL и ограничением размера

Решение. До 128 успешных генераций на процесс. Ключ включает модель, версию
промпта и отправленные сообщения, включая профиль, teacher_id, count и focus.
Запись выполняется после проверки структуры. Ручная перегенерация кэш обходит.

Цена решения. Повтор в пределах TTL получает те же кандидаты. При рестарте
записи теряются, между процессами кэш не разделяется. По умолчанию TTL равен
нулю. Перед общим включением нужно решить, где повторная выдача уместна в UX.

## 3. Инструмент истории с ограниченными правами

Решение. Функция `read_topic_history` получает данные только из уже выбранного
сервером профиля. Один вызов инструмента на генерацию, параметры проверяет
приложение. При отказе возвращаемся к генерации с контекстом обычного профиля.

Цена решения. Дополнительный вызов модели увеличивает цену и задержку.
Инструмент выключен по умолчанию. В режиме инструмента кэш отключён. Общая
авторизация HTTP-запросов остаётся задачей интеграции с командным приложением.
