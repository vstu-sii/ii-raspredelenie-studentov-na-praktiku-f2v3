# Глоссарий команды

Единый язык команды (как в DDD): термин звучит одинаково в документах,
use cases, коде и у агентов. Согласован вслух командой. Пополняется весь курс.

| Термин | Определение |
|---|---|
| ВКР | Выпускная квалификационная работа: всё, что студент делает на последнем курсе для защиты |
| Цикл ВКР | Один годовой проход процесса: от запуска в сентябре до защиты в июне |
| Окно регламента | Интервал дат, в который этап должен быть выполнен: просмотр — несколько дней, предзащита — один день |
| Замзав | Заместитель заведующего кафедрой по учебной части; владелец цикла ВКР, наш основной сегмент |
| Руководитель ВКР | Преподаватель, ведущий работу конкретного студента |
| Рецензент (просмотрщик) | Преподаватель, не являющийся руководителем студента; смотрит работу на просмотрах |
| Шаффл рецензентов | Автоматический подбор рецензентов без повторов с прошлых просмотров |
| Просмотр №1 / №2 | Промежуточные контрольные точки (зима/весна): два рецензента ставят оценку и комментарий |
| Предзащита | Публичный прогон перед комиссией из трёх преподавателей в мае, один день, слоты по времени |
| Допуск | Формальное право идти на защиту: пройдены нормоконтроль и антиплагиат |
| Защита | Финальное выступление перед комиссией с выставлением оценки |
| Приказ | Документ ректората, закрепляющий темы за студентами |
| Проект приказа | Черновик приказа до подписи ректоратом |
| Пара «студент — тема» | Результат второго круга подачи: фамилия + финальная формулировка для приказа |
| Каталог тем | Публичный в системе список тем от руководителей, без фамилий студентов |
| Трекер | Наша система: статусы, сроки, напоминания, автопроверки |
| Рефчекер | Модуль: DOI/ISBN/URL → метаданные из внешних источников → строка по ГОСТ |
| Библиографическая запись | Описание одного источника по ГОСТ Р 7.0.5-2008 |
| Список литературы | ≥30 записей, ≥20 % зарубежных, с обязательными базами: библиотека вуза, eLIBRARY, Scopus, интернет |
| DOI / ISBN | Идентификаторы источника, по которым рефчекер тянет метаданные |
| eLIBRARY / Scopus | Российская и международная базы научных публикаций; обязательные в списке |
| Пояснительная записка | Текст ВКР; сдаётся в PDF — Word, Typst или LaTeX неразличимы для проверки |
| Нормоконтроль | Проверка соответствия оформления: поля, кегль, интервалы, порядок разделов |
| Нормоконтролёр | Человек, подтверждающий результат автопроверки; нужен ли после LLM — открытый вопрос |
| LLM-нормоконтроль | Содержательная проверка PDF моделью по требованиям методички |
| Архив с кодом | Код ВКР, сдаётся отдельным архивом; в записку не вкладывается |
| LLM-ревью кода | Разбор архива моделью: качество, стиль, соответствие заданию; замечания с файлами и строками |
| Антиплагиат | Внешняя ручная проверка оригинальности со справкой; вне нашего скоупа |
| Пакет документов | Титульный лист + задание + справка антиплагиата + подписанный список литературы |
| North Star | Главная метрика продукта: ≥90 % этапов цикла в срок без личных напоминаний замзава |
| Golden dataset | Эталонные пары «вход — ожидание» для оценки качества проверок |
| Деградация | Режим при недоступности LLM: детерминированные проверки работают, LLM-этапы — в очередь с флагом «вручную» |
