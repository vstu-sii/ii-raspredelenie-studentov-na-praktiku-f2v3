# Definition of Done инкремента — ВКР-трекер

Дата: 12.11.2026 · Владелец: Product/VO · Применяется: еженедельная
приёмка (`acceptance.md`), закрытие вех (`roadmap.md`).

Правило: «готово» = критерии проверены, а не «кажется, готово».
Долг без владельца и срока не считается закрытым. Файл существовал в
роадмапе как ссылка с лабы 2 — теперь определение зафиксировано текстом.

## Инкремент кода

- Тесты зелёные в CI на PR: `ci.yml` (ruff, docker build); для AI-части —
  pytest и mock-прогон (`lab4-ai-ci.yml`).
- Если изменение меняет поведение AI-части: прогон evals до/после
  приложен, артефакты в репо (формат `experiments/lab4.md`).
- Контракт обновлён вместе с кодом: `api/openapi.yaml`, `ai-pipeline.md`,
  `database/schema.sql`. Рассинхрон спеки и кода — дефект E8
  (eval-report-1), к приёмке не допускается.
- Откат возможен: revert одной командой; миграции обратно совместимы.

## Документ

- Отвечает на вопрос шага/вехи, а не пересказывает спеку.
- Цифры — только из реальных прогонов, артефакт указан (`summary.json`
  и т. п.); mock-прогон помечен `is_model_benchmark: false`.
- Честная граница помечена явно: что не доказано, что заполняется
  последующими срезами. Пустой раздел лучше обещания «потом допишу».
- Термины сверены с глоссарием.

## Эксперимент

- Воспроизводится одной командой из репо: данные, скрипт/ноутбук,
  команда запуска приложены.
- Вывод записан как решение: что сравнивали, что показали цифры, какой
  вариант выбрали, какова цена выбора.

## Приёмка инкремента

- Владелец роли показывает результат на синхре (демо, файл, прогон);
  Product/VO проверяет по этому DoD.
- Результат — «принято» или «отклонено задачей» в борде `burndown.md`
  (владелец + срок). Устных «поправим потом» не бывает: отклонение без
  задачи приёмкой не считается завершённым.
