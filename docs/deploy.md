# Деплой

Прод живёт с первой недели и только наращивается.

## Лаба 1: hello-world (текущий прод)

Хостинг: **GitHub Pages** — раздаёт статику из ветки репозитория.
Выбран как доступный из РФ без VPN для любого члена команды и проверяющего.

- Прод-URL: https://vstu-sii.github.io/ii-raspredelenie-studentov-na-praktiku-f2v3/
- Что отдаёт: `public/index.html` — заглушка со статусом «ok»

### Как обновить прод

1. Изменить `public/index.html`
2. Запушить в ветку прод (через PR с зелёным CI)
3. Pages пересобирает сайт сам за 1–3 минуты

### Настройка (один раз)

Settings → Pages → Source: Deploy from a branch → ветка с кодом, папка `/ (root)` → Save.

### Почему статика, а не бэкенд

FastAPI-бэкенд собирается в Docker-образ и проверяется в CI (`docker build`)
на каждый PR с лабы 1. Размещение бэкенда требует Docker-хостинга — команда
выбирает его в лабе 2+ (критерий: публичный URL без VPN). Render и Hugging
Face Spaces рассматривались и отложены: недоступность из РФ без VPN.

## Проверка живости прода

Открыть прод-URL: виден статус «ok» — прод жив.
