# UC-01: Запустить цикл ВКР

**Актёр:** Замзав
**Цель:** Открыть годовой цикл ВКР: задать окна регламента, получить расписание этапов и план напоминаний — без ручной рассылки и согласований в переписках.
**Контекст:** Сентябрь, начало учебного года. До трекера даты этапов согласовывались в личных переписках с каждым руководителем.
**Триггер:** Начался новый учебный год.
**Предусловие:** Замзав залогинен в трекере.

## Шаги
1. Замзав открывает раздел «Циклы» и нажимает «Новый цикл».
2. Замзав выбирает окна регламента для этапов: наполнение каталога тем,
   подача пар, просмотр №1 (зима), просмотр №2 (весна), предзащита (май) —
   из предложенных интервалов дат.
3. (Опционально) Замзав правит конкретные даты внутри окон — для
   нестандартных случаев, когда окно регламента по умолчанию не подходит.
4. Система раскладывает дедлайны по этапам и создаёт план напоминаний
   студентам, руководителям и рецензентам.
5. Система показывает сводку цикла: этапы, окна, число подключённых
   руководителей.

## Результат
Цикл ВКР активен. Календарь этапов виден всем участникам. Напоминания
запланированы автоматически — замзав не отправил ни одного личного сообщения.

## Альтернативный поток
А1. По ходу цикла нужно подвинуть дату этапа: замзав выбирает этап и новое
    окно регламента, система пересчитывает связанные сроки и рассылает
    уведомления всем затронутым участникам.

## Связи
Фундамент для UC-02…UC-06: все этапы наследуют окна и дедлайны отсюда.
Источник данных для North Star (≥ 90 % этапов в срок без личных напоминаний).
