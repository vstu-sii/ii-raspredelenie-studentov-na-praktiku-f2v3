# UC-06: Отследить статус цикла

**Актёр:** Замзав
**Цель:** Видеть картину «кто застрял» по всем этапам цикла на одном экране — без обзвона, личных сообщений и сводных таблиц руками.
**Контекст:** Весь цикл, сентябрь–май. До трекера картина появлялась постфактум: замзав узнавал о просрочке, когда этап уже провален или кто-то пожаловался.
**Триггер:** Замзав открывает дашборд цикла.
**Предусловие:** Цикл запущен (UC-01), этапы имеют окна и дедлайны.

## Шаги
1. Замзав открывает дашборд цикла.
2. Система показывает статусы этапов по всем студентам: где окно идёт,
   где просрочка, где этап закрыт в срок.
3. Замзав фильтрует картину по этапу: каталог тем, подача пар, приказ,
   источники, просмотр №1, просмотр №2.
4. По каждой просрочке замзав видит, кому и когда система уже напомнила.
5. Замзав вмешивается только точечно: продлить окно (А1) или напомнить
   лично — в остальных случаях система ведёт себя сама.

## Результат
Замзав получает ответ на вопрос «кто застрял» за один экран и без единого
личного сообщения. Данные этого экрана — источник North Star: доля этапов,
закрытых в срок без личных напоминаний (цель ≥ 90 % к маю, считается
по данным трекера).

## Альтернативные потоки
А1. Замзав продлевает окно этапа: система пересчитывает связанные сроки
    и рассылает уведомления затронутым участникам — как при правке дат
    в UC-01.

## Связи
Боли PRD №1–2. Сюда стекаются просрочки из UC-02, UC-03, UC-05.
North Star измеряется данными этого экрана — критерии успеха из брифа:
≥ 90 % этапов в срок; проект приказа ≤ 1 дня; просрочка видна в день
возникновения.
