# Model Candidates — Lab 2 / AI Engineer

> Статус: **Accepted for MVP**. Основная модель `ministral-8b-2512`, резервный *явно выбираемый* вариант `ministral-3b-2512`.
>
> Обновление 15.10.2026: добавлены именованные альтернативы, единые критерии, сопоставимый расчёт стоимости и аргументация выбора. Сравнение характеристик — кабинетное; сравнительный прогон качества на одинаковом golden dataset **ещё не выполнен**. Не следует выдавать расчёт цены за эксперимент качества.

## 1. Задача и ограничения

Система генерирует кандидаты тем ВКР для направления **09.03.01 «Информатика и вычислительная техника»**. Входные данные: научные направления преподавателя, ранее одобренные темы, дополнительный `focus` администратора. Первый LLM-вызов обязан возвращать **структурированный** `teacher_id + titles[]`. После него работают локальный Quality Gate, проверка дубликатов и ручное подтверждение.

Нужны: русский язык; JSON/Structured Outputs; программный API; предсказуемая тарификация; управление задержками и retry; запись фактической модели (provenance); минимизация передаваемых персональных данных. Секреты и личные контакты не включаются в prompt.

## 2. Критерии выбора — одинаковые для всех кандидатов

| Критерий | Как сравниваем | Статус |
|---|---|---|
| C1. Контракт и JSON | Есть ли документированная поддержка структурированных ответов; результат проходит нашу JSON Schema | **Обязательный**, фактическую совместимость проверять spike |
| C2. Язык и релевантность | Доля тем, одобренных экспертом; соответствие направлениям; дубли | **Обязательный**, пока **нет сопоставимых измерений** по всем моделям |
| C3. Стоимость | USD за 6000 входных + 2000 выходных токенов при стандартном API | Сопоставимый расчёт по открытым тарифам |
| C4. Доступность и интеграция | Есть ли API, ключ, работающий клиент, лимиты, retry | В MVP практически интегрирована Mistral 8B |
| C5. Приватность и эксплуатация | Облачная передача профиля или локальный сервер; цена развёртывания | Качественная оценка рисков |
| C6. Воспроизводимость | Стабильный model ID, версия промпта, трейс вызова и token usage | Требование к реализации |

Правило выбора: **сначала** пригодность для C1/C2 и доступность C4, **затем** цена C3. Дешёвую модель нельзя объявить лучшей без успешной проверки качества C2. На текущем этапе C2 остаётся нерешённым для межпровайдерного сравнения — поэтому выбор предварительный и основан на проверенной интеграции, а не на заявленном «лучшем качестве».

## 3. Альтернативы и сравнение

Все суммы ниже — **стандартный платный API, текстовые токены, USD**. Цены могут меняться; указаны по публичным тарифным страницам, просмотренным 15.10.2026. Не учитываются кэш, пакетные скидки, дополнительные AI-repair, embedding и эксплуатация.

| Кандидат (конкретный model ID) | Structured output | Input / 1M | Output / 1M | Расчёт 6k input + 2k output | Решение |
|---|---|---:|---:|---:|---|
| **Ministral 3 8B — `ministral-8b-2512`** | Документирован; JSON-контракт интегрирован в прототип | $0.15 | $0.15 | **$0.0012** | **Основная модель MVP** |
| **Ministral 3 3B — `ministral-3b-2512`** | Документирован | $0.10 | $0.10 | **$0.0008** | Явный дешёвый режим, качество требует A/B-проверки |
| **Gemini 2.5 Flash-Lite — `gemini-2.5-flash-lite`** | Документирован | $0.10 | $0.40 | **$0.0014** | Альтернатива другого провайдера; интеграция и доступность требуют проверки |
| **OpenAI GPT-4.1 mini — `gpt-4.1-mini`** | Поддерживает структурированные ответы через API | $0.40 | $1.60 | **$0.0056** | Более дорогой вариант для контрольного эксперимента; сейчас не интегрирован |

**Расчёт:** `(6000 × input_price + 2000 × output_price) / 1_000_000`.
Например, для Mistral 8B: `(6000 × $0.15 + 2000 × $0.15) / 1_000_000 = $0.0012`.
Для 1000 таких запросов: 8B ≈ $1.20; 3B ≈ $0.80; Flash-Lite ≈ $1.40; GPT-4.1 mini ≈ $5.60 (без дополнительных вызовов и инфраструктуры).

**Ограничения сравнения:**
- Поддержка Structured Outputs у провайдера не доказывает, что модель идеально следует **нашей** схеме; это проверяется одинаковыми тестами.
- Нет независимых измерений релевантности, процентилей latency, числа retries, успешности JSON для всех четырёх кандидатов; оценки «лучше по качеству», «быстрее» **не заявляются**.
- Доступность Gemini 2.5 Flash-Lite для новых аккаунтов может быть ограничена; перед миграцией нужна проверка квот и допуска.
- GPT-4.1 mini указан для технического сопоставления по доступной документации; статус модели и пригодность для новых проектов необходимо перепроверять перед внедрением.

## 4. Решение и почему не альтернативы

**Принято: `ministral-8b-2512`.** Это не утверждение об абсолютном лидерстве модели на русском языке. Это инженерное решение для текущего MVP, потому что:
1. Уже существует работавшая интеграция Mistral и наблюдения на сценарии нашего продукта; переписывать провайдера для первого baseline — дополнительный риск.
2. Модель поддерживает API и структурированный вывод, нужный для `teacher_id + titles[]`.
3. Цена $0.0012 на одинаковый условный сценарий мала относительно стоимости ручной проверки.
4. Единый зафиксированный model ID, prompt version и provenance позволят сравнить версии и не смешивать результаты.

**Почему не 3B как основная?** Стоит на треть дешевле ($0.0008), но нет сопоставимого прогона по качеству профильных тем. Цена без качества — недостаточное основание.

**Почему не Gemini Flash-Lite?** Сопоставимая цена ($0.0014 в нашем сценарии), но это отдельная API-интеграция и тест доступности; явного преимущества качества пока не доказано.

**Почему не GPT-4.1 mini?** Для расчётного сценария $0.0056 (≈4.7 раза дороже 8B), при этом доказанного прироста качества тем ВКР нет. Можно использовать как контрольную модель в будущем эксперименте.

**Почему не локальный Ollama/Llama как основной?** Потенциально меньше отправляемых во внешний API данных, но нужны железо, обслуживание, мониторинг и отдельный эксперимент по русскому языку и схеме вывода. Без этих измерений локальный вариант не сравним по итоговой стоимости владения. Это **архитектурная альтернатива**, а не измеренный пятый кандидат.

## 5. Деградированный режим и ошибки

Основной поток:
`ministral-8b-2512 → JSON Schema → local Quality Gate → similarity → manual review`.

Если timeout / rate limit / API 5xx: ограниченный retry с backoff, после исчерпания попыток — **явная ошибка**; AI не подменяется локальным demo-банком.

Явный degraded mode: новый отдельный batch на `ministral-3b-2512`, обязательно `generation_model=ministral-3b-2512`, `generation_source=mistral-ai`; результаты идут на ручную проверку. **Автоматическое** переключение на 3B по умолчанию выключено (`MISTRAL_ALLOW_SMALL_FALLBACK=false`), чтобы не смешивать модели в одном эксперименте.

## 6. Цена решения помимо API-токенов

- **Деньги:** $0.0012/условный запрос на 8B; дополнительные retries, repair и эмбеддинги увеличивают итоговую цену.
- **Приватность:** профиль преподавателя и старые темы передаются внешнему провайдеру. Передаём только необходимые данные; не отправляем личные контакты и секреты.
- **Доступность:** интернет, rate limits, региональная доступность, состояние API.
- **Инфраструктура:** API, логирование, версионирование промптов, JSON Schema, retry, локальные embeddings, Quality Gate, ручное утверждение.
- **Цена качества:** дешёвый ответ может увеличить время ручной проверки и число отвергнутых/повторно сгенерированных тем.

## 7. План честной проверки выбора в Lab 3 / Lab 4

Для каждой модели на **одинаковом golden dataset**:
- ≥100 тем на модель (одинаковый набор преподавателей, число тем, температура/семплинг по возможности и prompt);
- успешность схемы JSON, соответствие профилю, новизна, доля дублей, доля утверждённых без правок;
- медиана и p95 latency, input/output tokens, цена с учётом retries;
- отдельно метод и время similarity, чтобы не путать retrieval/Quality Gate с временем генерации;
- сохранять model ID, prompt version, входной набор, ответ и raw usage (с исключением персональных данных и секретов из общедоступных логов).

**Пересмотреть решение**, если: качество passed <80%, error/timeout >5% на серии ≥100 запросов, >1 repair на преподавателя, тариф или доступность ухудшились, появилась строгая политика локальной обработки, или другая модель статистически лучше при сопоставимой полной цене.

На дату обновления сравнительный live-run **ещё не проведён**. Таблица выше — сравнение документации и расчёт бюджета, а не результаты оценочного стенда.
