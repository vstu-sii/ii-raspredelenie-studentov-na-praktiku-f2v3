# Кандидаты моделей и токен-бюджет

## Сценарий

Основной сценарий MVP — генерация тем ВКР по профилю преподавателя и данным кафедры.

Оценка одного запроса:

- вход: ~6000 токенов;
- выход: ~2000 токенов.

## 1. OpenAI GPT-5.6 Terra

Облачная модель.

На момент подготовки лабораторной тариф:

- input: $2 / 1M токенов;
- output: $12 / 1M токенов.

Расчёт:

6000 × $2 / 1 000 000 = $0.012

2000 × $12 / 1 000 000 = $0.024

Итого: **≈ $0.036 за сценарий**.

Источник: [OpenAI Models — ВСТАВИТЬ ССЫЛКУ]

## 2. YandexGPT Pro 5.1

Российская облачная модель.

Тариф:

- 0.8 ₽ / 1000 входных токенов;
- 0.8 ₽ / 1000 выходных токенов.

Для 6000 входных и 2000 выходных токенов:

6 × 0.8 + 2 × 0.8 = **6.4 ₽ за сценарий**.

Источник: [Yandex AI Studio Pricing — ВСТАВИТЬ ССЫЛКУ]

## 3. Qwen3-8B

Open-source модель с лицензией Apache 2.0.

Может быть развёрнута локально через Transformers.

При локальном запуске отсутствует оплата API за каждый токен, но появляются расходы на вычислительное оборудование и поддержку инфраструктуры.

Источник: [Qwen3-8B — ВСТАВИТЬ ССЫЛКУ]

## Сравнение

| Модель | Размещение | Стоимость | Плюсы | Минусы |
|---|---|---|---|---|
| GPT-5.6 Terra | облако | ≈ $0.036/сценарий | простая интеграция, сильная LLM | внешнее API |
| YandexGPT Pro 5.1 | облако | ≈ 6.4 ₽/сценарий | российская инфраструктура | зависимость от облака |
| Qwen3-8B | локально | API = 0 | данные остаются локально | требуется своё железо |

## Предварительный выбор

Для MVP выбираем облачную модель.

Целевой лимит стоимости: **не более $0.05 на стандартный сценарий**.

Если бюджет превышен:

1. уменьшаем объём RAG-контекста;
2. используем более дешёвую модель для простых операций;
3. кешируем повторно используемый контекст;
4. рассматриваем переход на локальную модель.
