# Model Candidates — AI Engineer

## Цель

Выбрать модель для MVP генерации тем ВКР по:

- профилю преподавателя;
- научным направлениям;
- прошлым одобренным темам.

Для честного сравнения стоимость считается для одного одинакового сценария:

- 6000 входных токенов;
- 2000 выходных токенов.

---

## Кандидат 1 — Ministral 3 8B

Идентификатор модели:

`ministral-8b-2512`

Модель поддерживает Chat Completions, Structured Outputs и контекст до 256k токенов.

Документация:

- https://docs.mistral.ai/models/ministral-3-8b-25-12

Цена:

- $0.15 / 1M input tokens;
- $0.15 / 1M output tokens.

Источник:

- https://docs.mistral.ai/inference/pricing

Расчёт одного сценария:

- input: 6000 × $0.15 / 1 000 000 = $0.0009;
- output: 2000 × $0.15 / 1 000 000 = $0.0003.

**Итого: ≈ $0.0012 за сценарий.**

Плюсы:

- уже подключена к нашему прототипу;
- проверена на реальной генерации;
- Structured Outputs;
- низкая стоимость;
- достаточно большой контекст.

Минусы:

- внешний облачный API;
- зависимость от rate limits и доступности сервиса;
- передаваемый контекст обрабатывается внешним провайдером.

---

## Кандидат 2 — GPT-4o

Модель:

`gpt-4o`

Официальная документация:

- https://developers.openai.com/api/docs/models/gpt-4o

Цена:

- $2.50 / 1M input tokens;
- $10 / 1M output tokens.

Расчёт одного сценария:

- input: 6000 × $2.50 / 1 000 000 = $0.015;
- output: 2000 × $10 / 1 000 000 = $0.020.

**Итого: ≈ $0.035 за сценарий, то есть около $0.036 при округлении.**

Плюсы:

- поддерживает Structured Outputs;
- большой контекст;
- развитый API.

Минусы:

- существенно дороже Ministral 3 8B в рассматриваемом сценарии;
- внешний облачный сервис;
- эксплуатация из России проблематична.

OpenAI публикует официальный перечень поддерживаемых стран. Россия в текущем списке отсутствует:

- https://help.openai.com/ru-ru/articles/5347006-which-countries-and-territories-are-supported-by-openai

## Кандидат 3 — YandexGPT Pro 5.1

Модель:

`YandexGPT Pro 5.1`

Документация:

- https://aistudio.yandex.ru/ru/docs/ai-studio/concepts/generation/models

YandexGPT Pro 5.1 имеет контекст 32k и доступна через API генерации текста и OpenAI-совместимые API.

Модель также поддерживает структурированный JSON-ответ.

Источник:

- https://aistudio.yandex.ru/ru/docs/ai-studio/operations/generation/completions-structured

Цена синхронного режима:

- 0.8 ₽ / 1000 input tokens;
- 0.8 ₽ / 1000 output tokens.

Источник:

- https://aistudio.yandex.ru/ru/docs/ai-studio/pricing

Расчёт одного сценария:

- input: 6 × 0.8 ₽ = 4.8 ₽;
- output: 2 × 0.8 ₽ = 1.6 ₽.

**Итого: ≈ 6.4 ₽ за сценарий.**

Плюсы:

- российская облачная инфраструктура;
- структурированные ответы;
- нет проблемы доступности OpenAI API из России.

Минусы:

- требуется отдельная интеграция;
- перед окончательным переходом необходимо провести тот же эксперимент на нашем наборе преподавателей.

## Итоговый выбор

Для текущего MVP выбираем:

**Ministral 3 8B (`ministral-8b-2512`).**

Это конкретный выбор, а не формулировка «используем облачную модель».

Причины:

1. модель уже интегрирована в рабочий прототип;
2. на ней проведён собственный эксперимент;
3. она поддерживает Structured Outputs;
4. стоимость рассматриваемого сценария составляет около $0.0012;
5. качество генерации достаточно для создания кандидатов тем при наличии отдельного Quality Gate.

Мы не утверждаем, что Ministral 3 8B является лучшей моделью вообще.

Выбор сделан именно для MVP с учётом:

- качества, наблюдаемого в нашем эксперименте;
- стоимости;
- простоты интеграции;
- необходимости быстро получить работающий pipeline.

GPT-4o и YandexGPT Pro 5.1 остаются кандидатами для дальнейшего сравнительного эксперимента.

## Цена выбранного решения

Использование облачной модели означает следующие издержки:

### API

Около $0.0012 на плановый сценарий 6000 input + 2000 output tokens.

### Конфиденциальность

Профили преподавателей и переданные модели тексты обрабатываются внешней облачной инфраструктурой.

Mistral сообщает, что по умолчанию данные размещаются в Европейском союзе:

- https://help.mistral.ai/en/articles/347629-where-do-you-store-my-data-or-my-organization-s-data

Для поддерживаемых stateless API существует Zero Data Retention:

- https://docs.mistral.ai/admin/monitor-comply/zero-data-retention

### Доступность

Система зависит от:

- сети;
- API Mistral;
- rate limits;
- текущих ограничений тарифа.

Поэтому локальный результат не должен незаметно выдаваться пользователю как результат облачной AI-модели.

### Дополнительная инфраструктура

Необходимо поддерживать:

- prompt;
- JSON Schema;
- обработку ошибок;
- проверку профильной релевантности;
- semantic similarity;
- хранение provenance результата.

При добавлении полноценного RAG дополнительно потребуются база знаний, embeddings, vector storage и контроль retrieval.
