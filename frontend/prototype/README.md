# Прототип UI — ВКР-трекер (Lab2)

Прототип ключевых экранов MVP. Сгенерирован агентом, лежит в репо
как код (as-code) — фигма и миро не используются.

## Запуск
Открыть index.html в браузере — без сборки и зависимостей.
Вкладки: Дашборд / Каталог тем / Просмотры.

## Экраны и UC
| Скриншот | Экран | Проверяемый UC |
|---|---|---|
| screenshots/dashboard.png | Дашборд цикла: статусы этапов, флаги просрочек | UC-06 (плюс итоги UC-01) |
| screenshots/catalog.png | Каталог тем: статус наполнения, перенос тем, подача пар | UC-02, UC-03 |
| screenshots/screening.png | Просмотры: карточки рецензентов, выставление оценки | UC-05 |

## Что проверяем прототипом
Прототип — для проверки UC, не для красоты: механика статусов,
просрочек и карточек читается с экрана. Рефчекер (UC-04) — экран
списка литературы студента, добавляется следующим при старте разработки.
