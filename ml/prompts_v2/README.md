# Версии промптов и прогоны

| Версия | Изменение | Проверка |
|---|---|---|
| `lab3-topics-v1` | Контрольный промпт из `ml/models/baseline.py` | Вариант A |
| `lab4-topics-v2` | Уточнены критерии повторов, профильности и обработки недоверенного ввода по E3/E4/E6 | A → B |
| `lab4-topics-v2-compact` | История сокращена до шести уникальных тем при том же системном промпте | B → C |

[Методика и решение](../../docs/experiments/lab4.md) связывают обе итерации
с [результатами прогона на Ministral 3B](../../docs/experiments/results/lab4-local-ministral3b/).
Версия каждого запроса записана в `requests.csv`, хэши системных промптов
и датасета — в `summary.json`. Рабочий вариант по умолчанию — v1.
