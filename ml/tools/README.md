# read_topic_history

Вход — `{"teacher_id": 1, "limit": 3}`. ID положительный, лимит от 1 до 6.
Успех — `{"status": "ok", "titles": ["…"]}`. Ошибки диспетчера:
`invalid_arguments`, `unknown_tool`, `forbidden`, `timeout`, `unavailable`.

Диспетчер сверяет ID с профилем, который уже выбран приложением для запроса.
Провайдер истории замкнут на этот профиль, доступа к произвольной БД, файлам,
секретам и операциям записи у функции нет. Таймаут чтения — 250 мс.
Таймаут отдельного HTTP-раунда выбора инструмента — 5 с. При отказе
или таймауте код продолжает обычную генерацию и пишет причину в трейсы.

Для пилота задать `AI_PROMPT_VARIANT=v2`, `AI_HISTORY_TOOL=true`,
`AI_CACHE_TTL_SECONDS=0`. Проверить на учебном профиле через существующий
`POST /api/generate/selected`. Для запуска с локальными трейсами задать
`AI_TRACING_MODE=local`. Сквозной вызов инструмента покрыт MockTransport;
совместимость с живым ответом проверяется при пилоте.
